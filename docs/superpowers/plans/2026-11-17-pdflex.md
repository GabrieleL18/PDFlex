# PDFlex Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** App Windows con due schede: editor di moduli PDF compilabili e confronto testuale di due PDF con export.

**Architecture:** Logica pura (modello campi, diff, export) in funzioni senza Qt, testate con pytest; le schede Qt le chiamano. PyMuPDF fa rendering, widget AcroForm ed estrazione parole; `difflib` fa il diff.

**Tech Stack:** Python 3.14 (`py`), PyMuPDF 2.1 (`import pymupdf`, non `fitz`), PySide6 6.12, pytest, PyInstaller. Venv già creato in `.venv`.

**Spec:** `docs/superpowers/specs/2026-11-17-pdflex-design.md`

## Global Constraints
- Interfaccia e messaggi in italiano.
- Mai sovrascrivere l'originale senza "Salva con nome" (il dialogo nativo chiede conferma se il file esiste).
- Tipi di campo: testo, multiriga, casella di spunta, radio, menu a tendina, data (`AFDate_FormatEx("dd/mm/yyyy")`), firma.
- Colori confronto: rimosso rosso `(1, 0, 0)`, aggiunto verde `(0, 0.7, 0)`, opacità 0.3.
- Diff: `difflib.SequenceMatcher(autojunk=False)` su parole, maiuscole conservate, spazi ignorati.
- Niente git commit: il progetto non è un repo e l'utente non l'ha chiesto.
- Comando test: `.venv/Scripts/python -m pytest -q`.

## Fatti verificati su PyMuPDF 2.1 (per non riscoprirli)
- `page.add_widget(w)` crea un campo padre per nome; widget radio con lo stesso `field_name` finiscono sotto lo stesso padre (gruppo corretto).
- **Bug:** lo stato "acceso" dei radio è sempre `/None` → tutti i bottoni del gruppo hanno lo stesso valore. Dopo `add_widget`, rinominare la chiave in `AP/N` (e `AP/D` se è un dict) da `/None` al valore del bottone con `doc.xref_set_key`, `AS` = `/Off`, e sul padre (`xref_get_key(w.xref, "Parent")`) `V` = `/Off`. Verificato: poi `on_state()` restituisce il valore.
- `w.script_format` viene scritto (padre ha `/AA<</F …>>`) ma rileggendo vale `None`: per riconoscere una data in caricamento cercare `AFDate` in `doc.xref_object(parent_xref)`.
- Obbligatorio = `w.field_flags |= pymupdf.PDF_FIELD_IS_REQUIRED`.
- `page.get_text("words")` → tuple `(x0, y0, x1, y1, testo, block, line, word)`.
- I font base14 (`helv`) non hanno `→` né molti caratteri Unicode: per il testo dell'export usare `fontfile="C:/Windows/Fonts/arial.ttf"` se esiste, altrimenti `helv`.

## Review Focus
1. Salvare sopra lo stesso file aperto (scelto in "Salva con nome") → deve funzionare, non dare errore di PyMuPDF. Test in Task 1.
2. PDF protetto da password o corrotto → messaggio chiaro in italiano, nessun crash. Test in Task 1 (`open_pdf`).
3. Due campi non-radio con lo stesso nome → verrebbero fusi in uno solo; il salvataggio deve rifiutarlo dicendo quali nomi. Test in Task 1.
4. Valore radio con spazi/accenti ("Sì grazie") → nome PDF non valido; va ripulito. Test in Task 1.
5. Contratto lungo (~20.000 parole per lato) → il diff deve finire in pochi secondi. Test in Task 2.

### Task 1: Pacchetto, apertura PDF e modello dei campi

**Files:**
- Create: `pdflex/__init__.py`, `pdflex/editor.py` (solo la parte modello in questo task), `requirements.txt`, `tests/test_editor_save.py`, `tests/conftest.py` (fixture `make_pdf(tmp_path, pages: list[str], rotate=0) -> Path` che crea un PDF con il testo dato, una stringa per pagina, via `insert_text`)

**Interfaces:**
- Produces:
  - `pdflex.open_pdf(path: str | Path) -> pymupdf.Document` — solleva `ValueError("Il PDF è protetto da password.")` se `needs_pass`, `ValueError("Impossibile aprire il PDF: <dettaglio>")` se l'apertura fallisce o non ha pagine.
  - `pdflex.editor.FIELD_KINDS = ("text", "multiline", "checkbox", "radio", "dropdown", "date", "signature")`
  - `@dataclass Field(kind: str, page: int, rect: tuple[float, float, float, float], name: str, required: bool = False, default: str = "", font_size: float = 0, options: list[str] = [], value: str = "")` — `options` per dropdown (una voce per elemento), `value` = valore del bottone radio, `default` per checkbox/radio = `"1"` se selezionato, `font_size` 0 = automatico.
  - `load_fields(doc: pymupdf.Document) -> list[Field]`
  - `save_with_fields(src_path: str | Path, fields: list[Field], out_path: str | Path) -> None` — rimuove i widget esistenti (`page.delete_widget`), riscrive tutti i campi, salva via `doc.tobytes()` + scrittura file (così `out_path == src_path` funziona). Solleva `ValueError("Nomi di campo duplicati: a, b")` per nomi ripetuti tra campi non-radio (o un nome usato sia da un radio sia da un non-radio).
  - `clean_value(s: str) -> str` — rimuove accenti (`unicodedata.normalize("NFKD")` + ascii), sostituisce ciò che non è `[A-Za-z0-9_-]` con `_`, stringa vuota → `"opzione"`.

### Task 2: Diff ed export del confronto

**Files:**
- Create: `pdflex/compare.py` (solo logica in questo task), `tests/test_compare.py`

**Interfaces:**
- Consumes: `open_pdf`
- Produces:
  - `@dataclass Word(page: int, rect: tuple[float, float, float, float], text: str)`
  - `@dataclass Change(kind: str, old: list[Word], new: list[Word], old_at: Word | None, new_at: Word | None)` — `kind` ∈ `"delete" | "insert" | "replace"`; `old_at`/`new_at` = parola dove scorrere su ciascun lato (per un insert, `old_at` = parola dell'originale nella posizione corrispondente, o l'ultima). Metodo `label() -> str`:
    - `"Rimosso (p. 3): testo"`, `"Aggiunto (p. 2): testo"`, `"Modificato (p. 1): vecchio → nuovo"`; pagine 1-based; ogni pezzo di testo troncato a 60 caratteri con `…`.
  - `extract_words(doc: pymupdf.Document) -> list[Word]`
  - `diff_words(old: list[Word], new: list[Word]) -> list[Change]` — confronto su `w.text`, un `Change` per ogni opcode non `equal`.
  - `export_report(old_path, new_path, changes: list[Change], out_path) -> None`:
    - Pagine di riepilogo A4 in testa: titolo "Confronto PDF", nomi dei due file, data (`gg/mm/aaaa hh:mm`), "Modifiche: N", poi una riga `label()` per modifica, testo a capo con `textwrap`, nuova pagina quando finisce lo spazio.
    - Poi per i = 0..max(pagine)-1: pagina larga `w_old + w_new`, alta il massimo; `show_pdf_page` dell'originale a sinistra e della nuova a destra (lato mancante bianco); rettangoli delle parole rimosse (sinistra) e aggiunte (destra) con `draw_rect(color=None, fill=…, fill_opacity=0.3)`, quelle a destra spostate di `w_old`.
